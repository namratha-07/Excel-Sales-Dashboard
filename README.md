## Excel Sales Dashboard

### Objective
Analyze bike sales data to identify trends and key performance metrics.

### Tools Used
- Microsoft Excel
- Pivot Tables
- Charts
- Data Cleaning

## Key Insights
- Bike purchases are higher among customers with greater average income, especially males.
- Middle-aged customers (31–54) represent the largest purchasing segment.
- Short commute distances (0–1 miles) show the highest likelihood of bike purchases.
- Purchasing behavior varies across regions, highlighting the importance of regional targeting.
- Customers with higher education levels tend to purchase bikes more frequently.
